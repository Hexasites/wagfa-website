# Downloadable files

Put PDFs, spreadsheets and other downloads here. They are copied to `site/files/` on every build.

Each file must also have an entry in `src/data/documents.json`. Until a file listed there exists in this folder, the website shows that document as "To be uploaded" and the build prints a reminder.

Files the site expects (from the current website's Help Files and Constitution pages):

| File name | Document |
| --- | --- |
| `record-claim-procedure.pdf` | Record Claim Procedure |
| `tournament-sanctioning-overview.pdf` | Tournament Sanctioning Pack: overview and requirements |
| `tournament-sanctioning-request.xlsx` | Sanctioning request form (spreadsheet) |
| `tournament-sanctioning-request.pdf` | Sanctioning request form (fillable PDF) |
| `tournament-report.xlsx` | Tournament report form (spreadsheet) |
| `tournament-report.pdf` | Tournament report form (fillable PDF) |
| `wagfa-constitution.pdf` | WAGFA Constitution |
| `wagfa-by-laws.pdf` | WAGFA By-laws |
| `historical-record-applications-1985-2018.pdf` | Historical record applications, 1985–2018 |

`wa-state-records.csv` is generated by the build from `src/data/records.json`; don't add it here.
